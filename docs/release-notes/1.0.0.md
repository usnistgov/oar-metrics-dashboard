## Metrics Dashboard 1.0.0

First release of the OAR PDR usage-metrics dashboard.

### Highlights

- Repository-wide KPIs: downloads, data volume, and user reach.
- Per-collection metrics views.
- Science Domains card, sortable by dataset count, downloads, users, or data volume.
- Most Accessed datasets with search, sort, and an adjustable count.
- Dataset detail drawer and a watchlist.

### Deployment

- Served as a static sub-app at `/metrics-dashboard/`.
